# 画像の配置場所

このフォルダに写真・ロゴを配置すると、サイトに自動で反映されます。
**現在：全スロットに写真を配置済み（2026-07-15）。** 元の高解像度PNGは
`assets/photos-original/` に保管しています（デプロイには含まれません）。

差し替えるときは、同じファイル名で上書きするだけで反映されます。
ファイルが無い場合は自動的にプレースホルダー表示に戻ります
（`src/data/site.ts` の `showImagePlaceholderLabels` を `true` にすると管理ラベルも表示）。

## ロゴについての注意（要確認）

現在の `logo.png`（ブランドビジュアル）は AI 生成のため、画像内の文字が一部崩れています
（「お葉参り」→正しくは「お墓参り」等）。背景付き長方形のためヘッダーの小さい表示にも不向きです。
そのためヘッダー／フッターは屋号のテキスト表示のままにしています（`site.ts` の `hasLogo: false`）。
文字が正しい透過背景ロゴが用意できたら、`logo.png` を差し替えて `hasLogo: true` にしてください。

写真は自動的にWebP/AVIFへ最適化され、遅延読み込み・アスペクト比固定（CLS防止）されます。
